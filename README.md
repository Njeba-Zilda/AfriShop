# AfriShop

Site vitrine d'AfriShop, une boutique de produits africains authentiques :
accueil, navigation, catalogue de produits et contact.

## Auteur
Njeba Zilda Beri

## Technologies
- HTML5
- CSS3 (Flexbox)
- Git et GitHub pour le versionnage

## Lancer le projet
1. Cloner le dépôt :
   `git clone https://github.com/Njeba-Zilda/AfriShop.git`
2. Ouvrir le dossier `AfriShop`.
3. Double-cliquer sur `index.html` pour l'ouvrir dans un navigateur.
